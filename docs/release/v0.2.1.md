# 默识 0.2.1

在 0.2 基础上的修正版本。

## 这个版本修正了什么

- **本地加载模型改为选择文件，而不是选择文件夹。** 原实现在「存储 → 模型管理」里点「从本地加载」时，弹出的是系统的**文件夹**选择器，容易被理解为在选保存位置。现在改为直接选择**已经下载好的模型文件**，并支持一次多选。
- 之所以支持多选，是因为部分模型需要多个权重文件：嵌入模型需要 2 个（`.tflite` 与 `sentencepiece.model`），语音模型需要 2 至 4 个（`.onnx` 与 `tokens.txt`）。
- 导入时的校验逻辑保持不变：仍按文件名匹配、校验字节数与哈希值，并且先在临时文件上完成全部校验，通过后才替换正式文件。因此**选错、选漏或权重下得不完整都不会破坏已下载的模型**，只会提示未找到完整的模型文件。

## 从 0.2 升级

- 与 0.2 使用**同一签名密钥**，`versionCode` 由 3 增至 4，可直接覆盖安装，无需卸载。
- 已下载的模型、已导入的知识库与设置均保留。

## 安装与使用前提

- **仅支持 arm64-v8a 的 64 位 ARM 真机**，系统需 Android 8.0（API 26）或更高。
- **模型需要首次在应用内下载**（Gemma 4 E2B / MiniCPM5-2B / Qwen3-0.6B 三选一；嵌入模型 Gecko 256 必装）。若不便联网下载，也可用「从本地加载」直接选择已下载好的模型文件。
- 云端引擎默认关闭，需要自行填写服务地址、密钥与模型名。

## 已知限制

- 扫描件型 PDF 与图片型 Word 内部没有可提取的文字，这类文件请改用截图 OCR。
- 单个导入文件上限 20 MB。
- 部分云端模型默认开启思考模式，会显著拉长响应时间；应用已针对该类端点关闭思考模式。

> 0.2 的功能更新（新增 MiniCPM5-2B、更新启动页图标）见 [v0.2 发布说明](v0.2.md)。
