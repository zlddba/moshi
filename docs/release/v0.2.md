# 默识 0.2

在 0.1.1 基础上的功能更新：新增一个可选的端侧对话模型，并更新应用图标。

## 这个版本新增了什么

- **新增可选端侧对话模型 MiniCPM5-2B（int8，约 2.55 GB）**：在「存储 → 模型管理 → 生成模型」中可下载并一键切换。它与现有的 Gemma 4 E2B、Qwen3-0.6B 并存，可随时切换，也可删除以释放空间。
- 该模型默认会先推理再作答，而本应用要的是"依据你的资料直接回答"，因此应用对它**显式关闭思考模式**，响应更快，也更契合知识库问答的场景。
- **应用启动页图标更新**：改用新版矢量图标；旧图标资源已无引用，一并删除。

## 从 0.1.1 升级

- 与 0.1.1 使用**同一签名密钥**，`versionCode` 由 2 增至 3，可直接覆盖安装，无需卸载。
- 已下载的模型、已导入的知识库与设置均保留。

## 关于新模型的两点说明

- 权重约 2.55 GB，首次下载耗时较长。下载**国内镜像优先**，失败会自动切换备用源，并按哈希与字节数**双重校验**，校验不通过不会入库。
- 应用同时只保留一个"当前对话模型"。**删除当前模型时，会自动切换到另一个已就绪的模型**；若没有其他可用模型，则保持当前选择并提示。

## 安装与使用前提

- **仅支持 arm64-v8a 的 64 位 ARM 真机**，系统需 Android 8.0（API 26）或更高。32 位 ARM 与 x86 设备无法安装，多数模拟器无法运行。
- **模型需要首次在应用内下载**：问答需要对话模型（可从 Gemma 4 E2B、MiniCPM5-2B、Qwen3-0.6B 中选其一；低端设备会自动降级为 Qwen3-0.6B），语义检索需要嵌入模型（Gecko 256）。模型不随安装包分发。
- 未下载嵌入模型时，语义检索会退化为纯关键词匹配。
- 云端引擎默认关闭，需要自行填写服务地址、密钥与模型名。

## 已知限制

- 扫描件型 PDF 与图片型 Word 内部没有可提取的文字，这类文件请改用截图 OCR。
- 单个导入文件上限 20 MB。
- 部分云端模型默认开启思考模式，会显著拉长响应时间；应用已针对该类端点关闭思考模式。
