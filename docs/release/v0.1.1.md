# 默识 0.1.1

在 0.1 基础上的小版本更新，只改动一处：应用图标。

## 这个版本改了什么

- **应用图标改用自适应图标体系**：背景由矢量绘制改为颜色资源，前景由矢量绘制改为各密度位图，并补齐 `mdpi` 至 `xxxhdpi` 五档前景图；锚点图标与圆角图标共用同一套前景资源。
- 原先自适应图标的 XML 引用的是 `drawable/` 下的矢量图，同时又存在各密度位图，同一套图标有两处来源。现统一引用 `mipmap` 与 `color`，`drawable/` 下那两份已无任何引用的矢量图一并删除。
- 除图标外，应用的功能与行为与 0.1 完全一致：未修改任何业务代码、依赖或构建配置。

## 从 0.1 升级

- 与 0.1 使用**同一签名密钥**，`versionCode` 由 1 增至 2，可直接覆盖安装，无需卸载。
- 若你此前安装的是自行编译的调试版，签名不同，需先卸载再安装。

## 安装与使用前提

- **仅支持 arm64-v8a 的 64 位 ARM 真机**，系统需 Android 8.0（API 26）或更高。32 位 ARM 与 x86 设备无法安装，多数模拟器无法运行。
- **模型需要首次在应用内下载**：问答需要对话模型（Gemma 4 E2B，低端设备自动降级为 Qwen3-0.6B），语义检索需要嵌入模型（Gecko 256）。模型不随安装包分发。
- 未下载嵌入模型时，语义检索会退化为纯关键词匹配。
- 云端引擎默认关闭，需要自行填写服务地址、密钥与模型名。

## 已知限制

- 扫描件型 PDF 与图片型 Word 内部没有可提取的文字，这类文件请改用截图 OCR。
- 单个导入文件上限 20 MB。
- 部分云端模型默认开启思考模式，会显著拉长响应时间；应用已针对该类端点关闭思考模式。

> 0.1 的完整功能说明见 [v0.1 发布说明](v0.1.md)。
