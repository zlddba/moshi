# 版本发布说明

每个版本一个文件，文件名与标签一致：`docs/release/v0.1.md` 对应标签 `v0.1`。

发布工作流会按标签名找到对应文件，并把它作为 GitHub Release 的正文：

```
标签 v0.1        → docs/release/v0.1.md
分支 release/v0.1 → docs/release/v0.1.md   （分支推送只构建，不创建 Release）
```

新建版本时复制上一版的文件再改内容即可。若对应文件不存在，工作流会退回到自动生成的
提交列表，并在日志中提示，不会因此失败。

建议每个版本说明包含：这一版能做什么、安装与使用前提、已知限制。
