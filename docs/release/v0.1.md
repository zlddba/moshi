# 默识 0.1

首个公开版本。端侧优先的个人知识库：把文档与笔记导入本机，分块、嵌入、检索与问答全部在设备本地闭环，回答只依据你自己的知识，并强制附带来源。

## 这个版本能做什么

- **完整闭环**：导入 → 分块 → 端侧嵌入 → 向量与关键词混合检索 → 端侧问答 → 来源标注。相关性不足时固定回复「知识库中没有找到相关内容」，不猜测、不编造。
- **混合检索**：向量召回（sqlite-vec，Gecko INT8 嵌入）与关键词召回（FTS5 trigram）经 RRF 融合，再按绝对阈值与相对最高分的比例双重过滤；首轮结果偏弱时用伪相关反馈补充查询，不额外调用模型。
- **多格式导入**：PDF、DOC/DOCX、XLS/XLSX、CSV/TSV、Markdown 与纯文本，以及截图 OCR（中文）与语音转写，全部在本机处理。
- **双引擎**：默认端侧推理，开箱可用；可在设置中填写 OpenAI 兼容的云端端点，页面上点击引擎徽标即可切换。云端只接收「你的问题 + 检索命中的片段」，标记为敏感的笔记在构造请求前就被过滤，永不外发。
- **本地加密**：可选 SQLCipher 加密数据库、AES-GCM 加密留存的原文件，并支持生物识别解锁。
- **知识图谱**：基于检索所用的同一套嵌入，建立笔记之间的相似度关系。

## 安装与使用前提

- **仅支持 arm64-v8a 的 64 位 ARM 真机**，系统需 Android 8.0（API 26）或更高。32 位 ARM 与 x86 设备无法安装，多数模拟器也无法运行。
- **模型需要首次在应用内下载**：问答需要对话模型（Gemma 4 E2B，低端设备自动降级为 Qwen3-0.6B），语义检索需要嵌入模型（Gecko 256）。模型不随安装包分发。
- 未下载嵌入模型时，语义检索会退化为纯关键词匹配。
- 云端引擎默认关闭，需要自行填写服务地址、密钥与模型名。

## 已知限制

- 扫描件型 PDF 与图片型 Word 内部没有可提取的文字，这类文件请改用截图 OCR。
- 单个导入文件上限 20 MB。
- 部分云端模型默认开启思考模式，会显著拉长响应时间；应用已针对该类端点关闭思考模式。
