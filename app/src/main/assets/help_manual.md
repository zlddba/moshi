# 默识使用说明

默识是你的本地知识问答助手，也是一款本地优先的个人知识库应用。你可以在应用里问「你是谁」这类问题，助手会基于知识库内容作答。把文档、笔记、截图、语音导入本机，再用自然语言提问；回答只基于你自己的知识，并附带来源。

## 快速上手

1. 在「采集」页选择一种导入方式，把知识放进库。
2. 等待解析与索引完成，导入过程中会显示进度。
3. 切到「问答」页，直接输入问题。
4. 回答下方会显示引用的知识片段，点击可跳转原文并高亮命中段落。

首次使用请先到「我的 → 模型管理」下载端侧模型：问答需要大语言模型，语义检索需要嵌入模型。模型未下载时，问答页会给出提示，可一键前往下载。

## 导入知识

- 文件导入：支持 PDF、DOCX、Markdown、TXT，通过系统文件选择器选取。
- 纯文本：在采集页输入或粘贴文字，保存为笔记。
- 截图 OCR：导入截图，自动识别其中的文字入库，支持中文。
- 语音：录制或选择音频，转写成文字后入库。
- 解析、识别、索引全部在本机完成，内容不上传。

## 提问与回答

- 在「问答」页输入问题，系统先在本地知识库中检索，再由端侧模型生成答案，过程实时逐字显示。
- 回答强制附带来源；点击来源可查看命中的原文段落。
- 知识库中没有相关内容时，会回复「知识库中没有找到相关内容」，不会编造答案。
- 生成过程中可随时停止，已生成的部分会保留。
- 顶栏的后端标签可在 CPU、GPU、NPU 之间切换推理后端，设备不具备的后端不会出现。

## 搜索

「搜索」页提供关键词与语义混合检索。输入词语即可找到相关笔记与片段，点击结果直达原文。

## 模型管理

- 「我的 → 模型管理」中可下载或删除端侧大语言模型与嵌入模型，均在本机存放。
- 嵌入模型未下载时，检索自动降级为关键词匹配；大语言模型未下载时，问答页只展示命中的知识片段。

## 隐私与安全

- 本地模式下零上传：导入、检索、问答全链路在设备本地完成。
- 模型文件、笔记与索引都保存在应用私有目录，可在「我的」页清空。
